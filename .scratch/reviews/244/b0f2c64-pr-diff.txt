+# #244 — a ratchet for raw-`.trim()` blankness gates, then the conversions
+
+- Tier: **High-assurance**. Justification: the conversions decide whether a
+  mark-only (bidi-mark-only) numeric draft is treated as *blank* or *chosen* in
+  money/stock readers — opening stock (failure mode 1: stock/avg cost), custom
+  return cash and settle amounts (mode 2: total computed wrongly) and payment /
+  debt previews (mode 3: debt direction). A wrong conversion records a number
+  the owner never saw, so the tier follows the failure mode, not the diff size
+  (`docs/engineering-workflow.md`). Recorded here as the brief requires.
+- Base: `origin/develop` @ `746ff933753a0b409e96365080c91e3ef6efb5b6`. `git
+  merge-base origin/develop HEAD` == base == HEAD (#243 squash for #238).
+- Authority: commit only. This lane does **not** push, open a PR, merge or write
+  `.agents/wisdom/`.
+
+## Problem
+
+#238 unified the *predicate* (`draftBlank`) at four sites, but left a
+hand-maintained list of the remaining raw-`.trim()` blankness gates. That list
+was found incomplete in review round 1 (*three* more real gates). A hand-written
+enumeration cannot be trusted, and "did we get them all?" is unanswerable by
+inspection. So the deliverable is the **ratchet**, not the conversions: a test
+that scans the numeric-draft readers for raw-`.trim()` blankness gates and fails
+on any gate that is not classified — either converted to `draftBlank`, or listed
+with a written reason it must stay raw.
+
+## The one invariant (unchanged from #238)
+
+Blankness is decided once, by the same normalisation the reader uses. Unify the
+*test*; preserve each site's *fallback* (#146: `cleared reads 0, digits read
+their value, unreadable keeps the previous`).
+
+## The ratchet
+
+`apps/web/src/lib/blankness-ratchet.test.ts`:
+
+- Scope = every non-test `apps/web/src/**/*.{ts,tsx}` that imports
+  `amount-parse` / `numeric-input` (the numeric-draft reader surface), plus the
+  two reader modules themselves. A new numeric reader in a new file imports a
+  reader, so it is scanned with no test edit.
+- A gate is a `X.trim()` compared to `""` (either operand order), or
+  `X.trim().length` compared to `0`, or the two-step
+  `const X = <expr>.trim(); … X === ""`. Receivers already normalised through
+  `normalizeArabicIndicDigits` (or `draftBlank`) are **not** raw and are skipped
+  — those readers need the normalised string.
+- Signature = `file::<canonical gate text>`; comment text is stripped first so a
+  docstring cannot create a gate.
+- `CLASSIFIED` is the whole enumeration. Verdicts:
+  - `raw` — the gate must stay a raw trim (non-numeric: name/reason/note/barcode/
+    date, or a deliberate UX work-indicator). Asserted **present**.
+  - `draftBlank` — the gate was converted. Asserted **absent**: re-introducing
+    the raw trim (the mutation) reddens the ratchet.
+  - A detected signature with no entry is **unclassified** → red.
+- A synthetic-source test pins the scanner itself.

+## Implementation risks
+
+- **Behaviour drift in a money reader.** Converting a gate changes mark-only
+  from a refusal to blank. Each conversion states its fallback in the table and
+  is pinned by a mark-only == blank test.
+- **Over-broad scanner.** A text gate wrongly converted would treat a real name
+  as empty. The scope is the numeric-reader import surface and the classification
+  names each raw gate; the scanner's NORM exclusion keeps normalised readers out.
+- **False negatives in the scanner.** Only `=== ""`/`!== ""`/`length === 0` and
+  the two-step form are matched. A future gate written another way is out of
+  scope by construction; the scanner comment says so.

+# #244 round 2 — the ratchet can be evaded; close the four evasions
+
+- Tier: **High-assurance** (recorded, unchanged from round 1). Justification: the
+  ratchet is the guard for the money/stock readers — a gate that slips through it
+  unclassified can record a numeric value the owner never saw (failure modes 1-3:
+  stock/avg-cost, totals, debt direction). The diff changes the guard itself, so
+  it can violate the same failure modes the guard exists to prevent. Tier follows
+  the failure mode, not the diff size (`docs/engineering-workflow.md`).
+- Round-2 delta base: `5fbe0f0` (= `origin/fix-244-blankness-ratchet`, the PR #246
+  head — the round-1 commit). This lane's commits sit on top of it. Merge-base
+  with `origin/develop`: `746ff933753a0b409e96365080c91e3ef6efb5b6` (#238 squash for
+  #243).
+- Authority: commit only. This lane does not push, open a PR, merge or write
+  `.agents/wisdom/`.
+- Specification: the Greptile comment on PR #246 (four findings) — read in full
+  before touching code. Round 1's design is `.scratch/implementation/244-design.md`.
+
+## Why this is the whole point of the PR
+
+The ratchet's value is that a new raw-`.trim()` gate turns CI red. All four
+findings let a gate through **unclassified** — the ratchet still *looks* green.
+So every fix here needs a **failing-first** demonstration: the gate escapes
+before, and is caught after. A scanner branch with no test that fails without it
+is edited, not fixed.
+
+## The four fixes
+
+### 1. Line layout hides checks (`apps/web/src/tests/blankness-gates.ts`)
+
+Two escapes, one cause: matching line-by-line and `continue`-ing a whole line
+once anything on it matched.
+
+- `draft.trim()` on one line and `=== ""` on the next returned no gate.
+- `name.trim() === "" || trimmed === ""` reported only the inline check: the
+  `if (inline) continue` skipped the rest of the line.
+
+Fix: strip comments, then run every matcher over the **whole source text**, and
+accept a match only when its `[start, end)` span does not overlap an
+already-accepted span. Inline forms win the priority order (`INLINE_FWD`,
+`PAREN_FWD`, `INLINE_REV`, `INLINE_LEN`, `INLINE_LEN_REV`, then the two-step
+`USE_FWD`/`USE_LEN_FWD`/`USE_REV`/`USE_LEN_REV`), so `"" === draft.trim()`'s
+reversed inline match claims its span before a two-step matcher can read
+`"" === draft` out of the middle of it — and `trimmed === ""` on a line that also
+holds an inline gate is no longer swallowed. Line numbers are recovered from the
+match offset (`1 + newlines before offset`), so the reported line stays the gate's
+own line.
+
+The declaration scan (`DECL`) also moves to the whole text and its right-hand
+side may cross a line break (`const trimmed =\n draft.trim();`), stopping at a
+statement break (`;`, `}`, or a new line that opens a new statement). That closes
+the sibling escape "write the declaration on two lines" that the line-by-line
+version also missed. It is **not** one of the four findings; it is the same
+defect class and it is cheap to close, so it is closed and tested.
+
+### 2. An inner variable hides an outer check (`blankness-gates.ts:154-158`)
+
+The lookup took the last earlier declaration **with the same name anywhere in the
+file**. A normalised declaration in a nested block therefore masked an outer raw
+`trimmed === ""`.
+
+Fix: give each declaration and each comparison a **scope chain** (the brace pairs
+that enclose its offset, computed on the comment-stripped text) and only accept a
+declaration whose chain is a prefix of the comparison's chain. The innermost
+visible declaration wins. Object-literal braces add depth but never break
+ancestry, so they are harmless; JSX `{}` and template `${}` are balanced.
+
+### 3. The mutation proof discards local edits (`.scratch/reviews/244/390da2d-mutation-proof.sh`)
+
+`git diff "$BASE" -- "$f"` folded uncommitted edits into the reversed patch, and
+`git checkout -- "$f"` then restored the **index** version, destroying them.
+
+Fix, in the cited file:
+
+- **Refuse to start** when any listed file is dirty (`git status --porcelain -- "$f"`).
+- **Preserve and restore exact bytes**: back every listed file up to a
+  `mktemp -d` copy before mutating, and restore from the copy in an `EXIT` trap —
+  independent of git's index.
+- `mktemp` for the patch file instead of a fixed `/tmp/mut.patch` (a shared path
+  two lanes can clobber).
+- Check `git apply -R` succeeded, and fail loudly if it did not.
+
+**Never `git stash`** (`.agents/wisdom/2026-10-14-git-stash-pathspec-pops-unrelated-stash.md`):
+`git stash push -- <path>` with nothing to stash pops an unrelated stash.
+
+The file keeps its `390da2d-` name (it is the tool the finding cites, and its logs
+are separate artifacts) but is now safe to rerun; the round-2 run is logged as
+`<round2-sha>-mutation-proof.log`.
+
+### 4. Two-step matchers lack self-tests (`blankness-ratchet.test.ts`)
+
+Added synthetic fixtures, in both directions, each of which must fail against the
+unfixed scanner:
+
+- forward two-step `const trimmed = draft.trim(); … trimmed === ""`,
+- reversed two-step `const trimmed = draft.trim(); … "" === trimmed`,
+- a **normalised** two-step declaration that must produce **no** gate,
+- the split-across-lines inline gate,
+- the inline-plus-two-step line,
+- the inner-scope-masks-outer raw gate.
+
+The reversed `USE` canonical text now keeps its operand order
+(`"" === trimmed [draft.trim()]`), matching the inline forms, so the two branches
+are distinguishable in `CLASSIFIED` and in evidence instead of collapsing onto one
+signature. No production gate is reversed, so `CLASSIFIED` does not change shape
+for it.
+
+## Deliberate ceiling (stated, not implied)
+
+The matcher stays **syntactic**. The round-1 ceiling stands: a bare truthiness
+gate (`if (!d.trim())`), a call-expression receiver (`f().trim()`), and a numeric
+gate in a file that does not import a reader are not caught. Added in round 2:
+
+- `var` hoisting / function-scope visibility is not modelled — only brace-scope
+  `const`/`let` declared at the declaration site, so a comparison of a `var`,
+  parameter, `catch` or post-`let`-assignment binding can be attributed to a
+  same-named visible declaration (false positive), and a value assigned after a
+  bare `let t; t = d.trim()` is not seen at all (false negative). An ASI-ambiguous
+  `const t = foo` above `bar.trim()` attributes that `.trim()` to `t` (false
+  positive with invented receiver text).
+- Regex literals are not parsed, so a regex holding a quote (e.g. `/['"]/`) or a
+  `/*` can mis-scope the file or **hide every later gate in it** (the unsafe
+  direction), and a comment after such a regex can be read as code (false
+  positive). Round 1 declined regex-literal parsing; round 2 states the severity
+  honestly and leaves it a **deferred follow-up**, because a half-lexer that
+  mis-reads division as a regex would create a new false negative.
+- A `.trim()` on the result of a call (`parseAmount(x).trim()`) is outside the
+  matched forms **inline** (`f().trim() === ""`); a two-step
+  `const t = f().trim()` **is** caught.
+- A relational `.length` test (`d.trim().length > 0`, `>= 1`) is not matched; only
+  the equality/inequality against `0` is (both operand orders, inline and two-step).
+- The blank operand must be a `""`/`''` literal; an empty template literal operand
+  is not matched.
+- A string or template literal whose **text** looks like a gate is scanned as
+  code (false positive). Blanking string bodies was **rejected**: it would also
+  hide a real gate inside a template `${}` expression, which is the unsafe
+  direction for a ratchet. A false positive only forces a `CLASSIFIED` line.
+
+Also outside the matched forms, and named here rather than only in the code:
+a receiver that is not a plain member chain — a call, an `as` cast, a
+parenthesised expression of more than one level (`((a ?? b) ?? c).trim()`),
+`draft!.trim()`, `draft.trim().trim()`, `drafts[
+ id
+].trim()`,
+`trimStart()`/`trimEnd()`, a space inside `.trim ()`; a value aliased
+(`const u = t`) or destructured; a second declarator on one line; a
+`switch (t) { case "" }` after a raw trim; a continuation line on the right-hand
+side. The reason for all of these is one: the matcher keys on a plain member
+chain compared to an empty literal, and each of those shapes is a different
+grammar production, so enumerating them would be an endless list rather than a
+boundary. They fail **closed** for a ratchet only if a real gate is written that
+way; `c143fa8-scanner-shapes.log` records which shapes it observed, so a reader
+can see the boundary rather than infer it.
+
+None of the four findings is in this ceiling; each of the four is fixed and
+pinned by a test that fails without the fix.
+

+
+Two facts, both in evidence: `gate-set-diff.sh` shows the **detected** gate set is
+identical (32 gates, `ADDED []`, `REMOVED []`) at `5fbe0f0`, `ad884d1`,
+`f30581c`, `f827d28` and `ba5a0b0`; and `git diff 5fbe0f0..c143fa8` over

+- **Scope model wrong → a gate silently drops out of the ratchet.** Two guards:
+  a red assertion when a `CLASSIFIED` signature's file leaves `numericReaderFiles()`,
+  and `.scratch/reviews/244/scope-shrink-proof.sh`, which narrows the surface and

+## Beyond the four findings (closed in this round)
+
+Escapes and over-reaches of the same class were found by the round-2 review lenses
+and closed here, each with a failing-first fixture (red before, green after):
+
+- **Reversed `.length`** (`0 === draft.trim().length`) — an evasion: the reversed
+  inline `=== ""` form was matched but the reversed `.length` form was not, an
+  asymmetry of exactly the kind finding 4 names.
+- **A receiver name that merely contains a normaliser name** — the inline
+  normaliser guard used a substring match, so `draftBlankish.trim() === ""` was
+  silently skipped. The normaliser is now matched as a **call** and the inline
+  check is gone: an inline receiver is a member chain, so it can never be a call.
+- **A property read attributed to a local** (`other.trimmed === ""`, and the
+  reversed `"" === trimmed.suffix`) — a false positive; closed with
+  `(?<![\w$.])` on the forward and `(?!\s*\.)` on the reversed two-step matcher.
+- **A `.trim()` chain the formatter broke across lines** (`draft\n  .trim() === ""`,
+  `draft.trim()\n  .length === 0`) — the chain matchers now allow whitespace inside
+  the chain; the canonical text still collapses it away.
+- **A declaration whose right-hand side holds a bracketed group**
+  (`parse({ raw: draft }).trim()`, `` `${draft}`.trim() ``) — the statement-break
+  check was a regex over `;`/`}`, so any `}` in an argument hid the declaration.
+  Replaced by a bracket-depth scan: only a `;`, a closing bracket at depth 0, or a
+  new statement ends the right-hand side.
+- **The two-step `.length` gate** (`const t = draft.trim(); t.length === 0`, either
+  operand order) — matched now, keyed on `.length` so ordinary numeric
+  comparisons against `0` are not swept in.

+#!/usr/bin/env bash
+# #244 mutation proof: revert each converted source file to its raw-.trim() form
+# (HEAD vs the pre-conversion BASE), run the ratchet, and capture the failure.
+# Restores after each file and on exit.
+#
+# The `390da2d-` name is historical (the round-1 head); this is the tool, the logs
+# are the per-SHA evidence. Hardened in round 2 for Greptile finding 3:
+#   * refuses to run when a listed file has uncommitted edits;
+#   * backs up each file and restores its exact bytes on EXIT, so a rerun can
+#     never destroy local edits (`git checkout -- <f>` restored the INDEX, not the
+#     original file, and `git diff "$BASE" -- "$f"` folded the edits into the
+#     reversed patch);
+#   * mktemp for the patch, so two lanes cannot clobber one /tmp/mut.patch;
+#   * fails loudly if the reverse patch does not apply.
+#
+# Round 3 (Greptile finding 3, the other half): a non-zero exit is NOT a detection.
+#   * refuses to start unless the unmutated ratchet is GREEN, so a runner error, a
+#     missing dependency or a bad reverse patch can no longer masquerade as a
+#     caught gate;
+#   * requires the EXPECTED assertion (`has every converted gate absent`) in the
+#     output, not merely a non-zero exit status.
+#
+# Never `git stash` here: `git stash push -- <path>` with nothing to stash pops an
+# unrelated stash (`.agents/wisdom/2026-10-14-git-stash-pathspec-pops-unrelated-stash.md`).
+set -u
+cd "$(dirname "$0")/../../.." || exit 1
+BASE="${1:-7f8f5c2}"
+FILES=(
+  apps/web/src/lib/numeric-input.ts
+  apps/web/src/lib/supplier-opening-draft.ts
+  apps/web/src/components/parties/supplier-return-draft.ts
+  apps/web/src/components/parties/supplier-return-panel.tsx
+  apps/web/src/components/ui/amount-percentage-input.tsx
+  apps/web/src/pages/invoice.tsx
+  apps/web/src/pages/items.tsx
+  apps/web/src/pages/stock.tsx
+  apps/web/src/components/parties/customer-settle-panel.tsx
+  apps/web/src/components/parties/supplier-pay-panel.tsx
+  apps/web/src/components/parties/supplier-adjust-panel.tsx
+)
+
+git rev-parse --verify --quiet "$BASE" > /dev/null || {
+  echo "REFUSING: BASE '$BASE' is not a commit in this repo"
+  exit 1
+}
+
+# Refuse a dirty listed file: the proof mutates these files by reverse-applying a
+# commit-range diff, which is only meaningful from the committed state.
+dirty=0
+for f in "${FILES[@]}"; do
+  if [ -n "$(git status --porcelain -- "$f")" ]; then
+    echo "REFUSING: $f has uncommitted changes; the proof would clobber them"
+    dirty=1
+  fi
+done
+[ "$dirty" -eq 0 ] || exit 1
+
+BACKUP_DIR="$(mktemp -d)"
+PATCH="$(mktemp)"
+OUT="$(mktemp)"
+restore() {
+  for i in "${!FILES[@]}"; do
+    if [ -f "$BACKUP_DIR/$i" ]; then
+      cp -p "$BACKUP_DIR/$i" "${FILES[$i]}"
+    fi
+  done
+  rm -rf "$BACKUP_DIR" "$PATCH" "$OUT"
+}
+trap restore EXIT
+
+for i in "${!FILES[@]}"; do
+  cp -p "${FILES[$i]}" "$BACKUP_DIR/$i" || {
+    echo "FATAL: could not back up ${FILES[$i]}"
+    exit 1
+  }
+done
+
+echo "=================== BASELINE (unmutated) ==================="
+( cd apps/web && bun test src/lib/blankness-ratchet.test.ts > "$OUT" 2>&1 )
+baseline=$?
+echo "baseline ratchet exit code: $baseline"
+if [ "$baseline" -ne 0 ]; then
+  echo "FATAL: the ratchet is not green before any mutation; a red run proves nothing"
+  grep -E '\(fail\)|error' "$OUT" | head -10
+  exit 1
+fi
+
+status=0
+for i in "${!FILES[@]}"; do
+  f="${FILES[$i]}"
+  echo "=================== MUTATION: revert $f ==================="
+  git diff "$BASE" -- "$f" > "$PATCH"
+  if ! git apply -R "$PATCH"; then
+    echo "FATAL: reverse patch did not apply to $f"
+    exit 1
+  fi
+  ( cd apps/web && bun test src/lib/blankness-ratchet.test.ts > "$OUT" 2>&1 )
+  code=$?
+  echo "ratchet exit code: $code"
+  grep -E '^\+   "|\(fail\)|has every converted gate absent|classifies every detected gate' "$OUT" | head -25
+  cp -p "$BACKUP_DIR/$i" "$f"
+  if [ "$code" -eq 0 ]; then
+    echo "PROBLEM: the ratchet stayed green on a reverted raw gate"
+    status=1
+  elif ! grep -qE '\(fail\).*(has every converted gate absent|classifies every DETECTED gate)' "$OUT"; then
+    echo "PROBLEM: exit $code without the expected failing assertion — a crashed runner is not a detection"
+    status=1
+  fi
+done
+
+leftover="$(git status --porcelain -- "${FILES[@]}")"
+if [ -n "$leftover" ]; then
+  echo "PROBLEM: restored tree still differs from the index:"
+  echo "$leftover"
+  status=1
+fi
+
+echo "=================== ALL FILES RESTORED ==================="
+git status --short -- "${FILES[@]}"
+exit "$status"

+# #244 round 2 — every scanner branch must be pinned.
+#
+# Finding 4's rule ("deleting the reversed USE branch would leave the suite green")
+# generalised: delete one matcher branch at a time and require the ratchet suite to
+# REDDEN. A branch whose deletion stays green is a branch with no test that fails
+# without it — i.e. edited, not fixed.
+#
+# Round 3 (Greptile finding 3): a non-zero exit is not a red suite. The untouched
+# suite must be GREEN before the first deletion, and each deletion must produce at
+# least one `(fail)` line — a crashed runner has no failing test to show.
+#
+# STATED CEILING: BRANCHES lists the ten matcher call sites only. The scanner's
+# internals (`scanSource`'s template/`${}` region tracking, `withoutSubscripts`,
+# the string-aware `breaksStatement`) are pinned by the fixture tests in
+# `blankness-ratchet.test.ts`, not by a deletion here.
+#
+# The scanner is backed up to a mktemp copy and restored on EXIT (never git stash).
+set -u

+  echo "REFUSING: $SCANNER has uncommitted changes"
+  exit 1
+}
+
+BACKUP="$(mktemp)"
+OUT="$(mktemp)"
+trap 'cp -p "$BACKUP" "$SCANNER"; rm -f "$BACKUP" "$OUT"' EXIT
+cp -p "$SCANNER" "$BACKUP"
+BEFORE="$(sha256sum "$SCANNER" | cut -d' ' -f1)"
+
+# Green baseline first: a suite that is already red proves nothing about a deletion.
+( cd apps/web && bun test src/lib/blankness-ratchet.test.ts > "$OUT" 2>&1 )
+baseline=$?
+if [ "$baseline" -ne 0 ]; then
+  echo "FATAL: the ratchet is not green before any branch deletion"
+  grep -E '\(fail\)|error' "$OUT" | head -10
+  exit 1
+fi
+echo "baseline ratchet exit code: 0"
+
+SCANNER="$SCANNER" BACKUP="$BACKUP" OUT="$OUT" python - <<'PY'
+import io, os, re, subprocess
+
+scanner = os.environ["SCANNER"]
+original = io.open(os.environ["BACKUP"], encoding="utf-8").read()
+out_path = os.environ["OUT"]
+
+BRANCHES = [
+    "INLINE_FWD",
+    "PAREN_FWD",
+    "PAREN_REV",
+    "INLINE_REV",
+    "INLINE_LEN",
+    "INLINE_LEN_REV",
+    "USE_FWD",
+    "USE_LEN_FWD",
+    "USE_REV",
+    "USE_LEN_REV",

+

+crashed = []
+for name in BRANCHES:
+    pattern = re.compile(r"\n  claim(?:Inline|TwoStep)\(\s*" + name + r"\b.*?\);\n", re.S)
+    match = pattern.search(original)
+    if match is None:
+        print(f"FATAL: no call site found for {name}")
+        raise SystemExit(2)
+    target = match.group(0)
+    assert original.count(target) == 1, name
+    with io.open(scanner, "w", encoding="utf-8", newline="\n") as handle:
+        handle.write(original.replace(target, "\n  ;\n"))
+
+    with io.open(out_path, "w", encoding="utf-8") as sink:
+        code = subprocess.run(
+            ["bun", "test", "src/lib/blankness-ratchet.test.ts"],
+            cwd="apps/web",
+            stdout=sink,
+            stderr=subprocess.STDOUT,
+        ).returncode
+    body = io.open(out_path, encoding="utf-8", errors="replace").read()
+    fails = [line for line in body.splitlines() if line.startswith("(fail)")]
+    print(f"--- delete {name}: exit {code}, {len(fails)} failing test(s)")
+    for line in fails[:3]:
+        print(f"    {line}")
+    if code == 0:
+        unpinned.append(name)
+    elif not fails:
+        crashed.append(name)
+
+with io.open(scanner, "w", encoding="utf-8", newline="\n") as handle:
+    handle.write(original)
+
+if crashed:

+        "— a crashed runner is not a detection"

+  exit 1
+fi
+echo "scanner restored byte-identical and green"
+exit "$result"

+#!/usr/bin/env bash
+# #244 round 2 — prove the scope assertion has teeth.
+#
+# `numericReaderFiles()` defines the ratchet's scanned surface. If it silently
+# shrinks, the ratchet keeps passing while a real gate leaves the surface: the
+# exact "still looks green" failure this PR exists to prevent. This narrows the
+# surface (drop the reader-import route) and shows the ratchet REDDENS, then
+# restores the file's exact bytes.
+#
+# Never `git stash`; the file is backed up to a mktemp copy and restored on EXIT.
+set -u
+cd "$(dirname "$0")/../../.." || exit 1
+SCANNER="apps/web/src/tests/blankness-gates.ts"
+
+[ -z "$(git status --porcelain -- "$SCANNER")" ] || {
+  echo "REFUSING: $SCANNER has uncommitted changes"
+  exit 1
+}
+
+BACKUP="$(mktemp)"
+OUT="$(mktemp)"
+trap 'cp -p "$BACKUP" "$SCANNER"; rm -f "$BACKUP" "$OUT"' EXIT
+cp -p "$SCANNER" "$BACKUP"
+BEFORE="$(sha256sum "$SCANNER" | cut -d' ' -f1)"
+
+# MUTATION: keep only the two reader modules in scope; the import route finds none.
+sed -i 's|const imported = all\.filter|const imported = [].filter|' "$SCANNER"
+grep -n "const imported = \[\]" "$SCANNER" || { echo "FATAL: mutation did not apply"; exit 1; }
+
+( cd apps/web && bun test src/lib/blankness-ratchet.test.ts > "$OUT" 2>&1 )
+mutated=$?
+echo "mutated ratchet exit code: $mutated"
+grep -E '^\(fail\)|\(pass\) raw-|names only files inside the scanned scope|keeps every gate marked raw|detected gate' "$OUT" | head -12
+
+cp -p "$BACKUP" "$SCANNER"
+( cd apps/web && bun test src/lib/blankness-ratchet.test.ts > "$OUT" 2>&1 )
+restored=$?
+echo "restored ratchet exit code: $restored"
+
+AFTER="$(sha256sum "$SCANNER" | cut -d' ' -f1)"
+leftover="$(git status --porcelain -- "$SCANNER")"
+status=0
+if [ "$mutated" -eq 0 ]; then
+  echo "PROBLEM: a shrunken scanned surface stayed green"
+  status=1
+fi
+if [ "$restored" -ne 0 ] || [ "$BEFORE" != "$AFTER" ] || [ -n "$leftover" ]; then
+  echo "PROBLEM: did not restore $SCANNER exactly (exit=$restored bytes=$BEFORE->$AFTER leftover='$leftover')"

+      continue;
+    }
+    if (region.kind === "template") {
+      if (char === "\\") {
+        out += char + (next ?? "");
+        i += 1;
+        continue;
+      }
+      if (char === "`") {
+        regions.pop();
+        out += char;
+        continue;
+      }
+      if (char === "$" && next === "{") {
+        // the interpolation braces are a scope, so a declaration inside `${}` is
+        // not visible to a comparison outside it
+        const at = out.length;
+        opens.push(at);
+        regions.push({ kind: "code", interpolation: at });
+        out += "${";
+        i += 1;
+        continue;
+      }
+      out += char;
+      continue;
+    }
+    // code region
+    if (char === "/" && next === "/") {
+      regions.push({ kind: "line" });
+      i += 1;
+      continue;
+    }
+    if (char === "/" && next === "*") {
+      regions.push({ kind: "block" });
+      i += 1;
+      continue;
+    }
+    if (char === "'" || char === '"') {
+      regions.push({ kind: "quote", terminator: char });
+      out += char;
+      continue;
+    }
+    if (char === "`") {
+      regions.push({ kind: "template" });
+      out += char;
+      continue;
+    }
+    if (char === "{") {
+      opens.push(out.length);
+      out += char;
+      continue;
+    }
+    if (char === "}") {
+      const open = opens.pop();
+      if (open !== undefined) braces.push({ open, close: out.length });
+      // only the interpolation's OWN brace ends the region: an inner `{...}` (an
+      // object literal, an arrow body) must not turn the rest of the template
+      // back into text, which would stop stripping its comments and scoping it
+      if (region.interpolation !== null && open === region.interpolation) regions.pop();
+      out += char;
+      continue;
+    }
+    out += char;
+  }
+  return { code: out, braces };
+}
+const collapse = (text: string) => text.replace(/\s+/g, " ").trim();
+
+interface Span {
+  readonly start: number;
+  readonly end: number;
+}
+
+interface BracePair {
+  readonly open: number;
+  readonly close: number;
+}
+
+/** The comment-stripped source and the brace pairs within it, from one pass. */
+interface ScanResult {
+  readonly code: string;
+  readonly braces: BracePair[];
+}

+interface Declaration {
+  readonly name: string;
+  /** The expression the `.trim()` was called on, e.g. `draft` or
+   * `normalizeArabicIndicDigits(draft)`, collapsed to one line. */
+  readonly rhs: string;
+  readonly offset: number;
+  readonly enclosing: readonly BracePair[];
+}
+
+/** The 1-based line a character offset sits on. */
+function lineAt(text: string, offset: number): number {
+  let line = 1;
+  for (let i = 0; i < offset; i += 1) if (text[i] === "\n") line += 1;
+  return line;
+}
+
+
+
+/** The brace pairs enclosing one offset — the scope chain of a token. */
+function enclosing(pairs: readonly BracePair[], offset: number): BracePair[] {
+  return pairs.filter((pair) => pair.open < offset && offset < pair.close);
+}
+
+/**
+ * Every `const`/`let X = <expr>.trim()` in the text, with its scope chain. The
+ * right-hand side may cross line breaks; a statement break before the `.trim()`
+ * means the `.trim()` is not this declaration's.
+ */
+function collectDeclarations(text: string, braces: readonly BracePair[]): Declaration[] {
+  const trimCalls: number[] = [];
+  for (const match of text.matchAll(new RegExp(DECL_TRIM, "g"))) trimCalls.push(match.index);
+  const declarations: Declaration[] = [];
+  for (const match of text.matchAll(DECL)) {
+    const offset = match.index;
+    const afterEquals = offset + match[0].length;
+    const trimOffset = trimCalls.find((candidate) => candidate >= afterEquals);
+    if (trimOffset === undefined) continue;
+    if (breaksStatement(text, afterEquals, trimOffset)) continue;
+    declarations.push({
+      name: match[1]!,
+      rhs: collapse(text.slice(afterEquals, trimOffset)),
+      offset,
+      enclosing: enclosing(braces, offset),
+    });
+  }
+  return declarations;
+}
+
+/**
+ * The innermost declaration of `name` that is visible at `offset`: earlier in the
+ * file, and whose scope chain is a prefix of the comparison's. A declaration in a
+ * nested block therefore cannot mask an outer one of the same name (#244 round 2,
+ * finding 2).
+ */
+function visibleDeclaration(
+  declarations: readonly Declaration[],
+  name: string,
+  offset: number,
+  comparisonScope: readonly BracePair[],
+): Declaration | undefined {
+  let found: Declaration | undefined;
+  for (const declaration of declarations) {
+    if (declaration.name !== name || declaration.offset >= offset) continue;
+    const visible = declaration.enclosing.every((pair) =>
+      comparisonScope.some((scope) => scope.open === pair.open),
+    );
+    if (visible) found = declaration;
+  }
+  return found;
+}

+/** Every raw-`.trim()` blankness gate in one source string. */
+export function findBlanknessGates(source: string, file: string): BlanknessGate[] {
+  const { code: text, braces } = scanSource(source);
+  const declarations = collectDeclarations(text, braces);
+
+  const bySignature = new Map<string, { offset: number; gate: BlanknessGate }>();
+  const claimed: Span[] = [];
+  const overlaps = (span: Span) =>
+    claimed.some((existing) => span.start < existing.end && existing.start < span.end);
+  const record = (offset: number, canonical: string) => {
+    const signature = `${file}::${canonical}`;
+    if (bySignature.has(signature)) return;
+    bySignature.set(signature, { offset, gate: { file, line: lineAt(text, offset), signature } });
+  };
+
+  // Inline forms first: they are the more specific match, and claiming their span
+  // stops a broader matcher reading a two-step gate out of their middle. A raw
+  // receiver is a member chain, so it can never be a normaliser CALL — the
+  // normaliser check belongs to a two-step declaration, not here.
+  const claimInline = (regex: RegExp, canonical: (match: RegExpExecArray) => string) => {
+    for (const match of text.matchAll(regex)) {
+      const start = match.index;
+      const span = { start, end: start + match[0].length };
+      if (overlaps(span)) continue;
+      claimed.push(span);
+      record(start, canonical(match));
+    }
+  };
+
+  // A `.trim()` chain may be broken across lines by the formatter, so the chain
+  // matchers allow whitespace inside it; the canonical text collapses it away.
+  claimInline(INLINE_FWD, (match) => `${collapse(match[1]!)}.trim() ${match[2]} ""`);
+  claimInline(
+    PAREN_FWD,
+    (match) => `(${collapse(match[1]!)} ?? ${collapse(match[2]!)}).trim() ${match[3]} ""`,
+  );
+  claimInline(
+    PAREN_REV,
+    (match) => `"" ${match[2]} (${collapse(match[3]!)} ?? ${collapse(match[4]!)}).trim()`,
+  );
+  claimInline(INLINE_REV, (match) => `"" ${match[2]} ${collapse(match[3]!)}.trim()`);
+  claimInline(INLINE_LEN, (match) => `${collapse(match[1]!)}.trim().length ${match[2]} 0`);
+  claimInline(INLINE_LEN_REV, (match) => `0 ${match[1]} ${collapse(match[2]!)}.trim().length`);
+
+  // Two-step: `const X = <expr>.trim(); … X === ""` / `X.length === 0`, in either
+  // operand order.
+  const claimTwoStep = (
+    regex: RegExp,
+    nameGroup: number,
+    operatorGroup: number,
+    canonical: (name: string, operator: string, rhs: string) => string,
+  ) => {
+    for (const match of text.matchAll(regex)) {
+      const start = match.index;
+      const span = { start, end: start + match[0].length };
+      if (overlaps(span)) continue;
+      const name = match[nameGroup] ?? "";
+      const operator = match[operatorGroup] ?? "";
+      const declaration = visibleDeclaration(declarations, name, start, enclosing(braces, start));
+      if (declaration === undefined || NORMALISED_VALUE.test(withoutSubscripts(declaration.rhs))) continue;
+      claimed.push(span);
+      record(start, canonical(name, operator, declaration.rhs));
+    }
+  };
+
+  const gateSuffix = (rhs: string) => `[${rhs}.trim()]`;
+  claimTwoStep(USE_FWD, 1, 2, (name, operator, rhs) => `${name} ${operator} "" ${gateSuffix(rhs)}`);
+  claimTwoStep(
+    USE_LEN_FWD,
+    1,
+    2,
+    (name, operator, rhs) => `${name}.length ${operator} 0 ${gateSuffix(rhs)}`,
+  );
+  claimTwoStep(USE_REV, 3, 2, (name, operator, rhs) => `"" ${operator} ${name} ${gateSuffix(rhs)}`);
+  claimTwoStep(
+    USE_LEN_REV,
+    2,
+    1,
+    (name, operator, rhs) => `0 ${operator} ${name}.length ${gateSuffix(rhs)}`,
+  );
+
+  return [...bySignature.values()].sort((a, b) => a.offset - b.offset).map((entry) => entry.gate);
+}
+
+function walk(dir: string, out: string[] = []): string[] {
+  for (const entry of readdirSync(dir)) {
+    const path = join(dir, entry);
+    if (statSync(path).isDirectory()) walk(path, out);
+    else if (/\.(ts|tsx)$/.test(entry)) out.push(path);
+  }
+  return out;
+}

+/**
+ * The ratchet's scope: every non-test source file that reads numerics through the
+ * shared readers (`amount-parse` / `numeric-input`), plus the reader modules
+ * themselves. A new numeric reader imports a reader, so it is scanned with no
+ * test edit.
+ */
+export function numericReaderFiles(): string[] {
+  const all = walk(srcRoot).filter((path) => !path.endsWith(".test.ts") && !path.endsWith(".test.tsx"));
+  const readers = ["lib/amount-parse.ts", "lib/numeric-input.ts"].map((path) => join(srcRoot, path));
+  const imported = all.filter((path) =>
+    /from\s+["'][^"']*\/(amount-parse|numeric-input)["']/.test(readFileSync(path, "utf8")),
+  );
+  const selected = new Set([...readers, ...imported]);
+  return [...selected].map((path) => relative(srcRoot, path).split("\\").join("/")).sort();
+}
+
+/** Every gate in the scope, ready for the classifier. */
+export function scanNumericDraftReaders(): BlanknessGate[] {
+  return numericReaderFiles().flatMap((file) =>
+    findBlanknessGates(readFileSync(join(srcRoot, file), "utf8"), file),
+  );
