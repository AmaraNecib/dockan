## Edge-case hunter

**Correct**
- The new test genuinely exercises the bit. Independent replication of the mock
  + migration + import microtask graph shows the ordering the test claims:
  `read-settled(null)` → `listener(ok=false, importing=true)` →
  `finally(importing=false)` → bit → retry. Reverting to `if (importing) return;`
  leaves the store unset, so the test is mutant-sensitive, not a false positive.
- One-bit invariant correct: no counter/array, so repeated refusals cannot grow
  state (`App.tsx:324`).
- Concurrent-import guard holds: the recursive call in `.finally` re-sets
  `importing = true` synchronously (`App.tsx:342-347`).

**Findings**
- 🟠 The retry's *own* `writePreference` failing is unrecovered (one level deeper
  than #115). `migrateLegacySidebarCollapsed` writes directly
  (`sidebar-state.ts:59`) and only `usePreference.send` notifies
  (`preferences.ts:176`); a failed retry write leaves the sidebar at the default
  until next launch. The test sets `failPreferenceWriteCount = 1`, so attempt #2
  succeeds and this path is uncovered. → **deferred** (pre-existing round-1
  behaviour, named candidate follow-up, see below).
- 🟠 Effect re-run on an `enabled` true→false→true toggle drops an in-flight
  refusal: `importing`/`retryPending` are effect-locals (`App.tsx:322-324`) and
  `enabled` is a dep (`App.tsx:362`); the old closure is unsubscribed and the new
  one has `retryPending = false`. → **deferred** (pre-existing round-1 effect
  shape; `enabled` toggling mid-flight is narrow — see candidate follow-ups).
- 🟡 Unmount during a pending retry still writes (`App.tsx:344-347`); no setState,
  so no warning, but a write can land post-teardown. → **deferred**.
- 🟡 Boundary/empty legacy values never tested: `""`, `"TRUE"`, `"0"` → import
  returns null and the legacy key is kept forever (`sidebar-state.ts:65-70`).
  → **deferred** (pre-existing behaviour, not round 2).
- 🟡 Two failed writes in a row cannot be reproduced: `preferenceWriteGate` nulls
  itself on first use (`App.test.tsx` mock). → **deferred** (coefficient below).

## Deferred (candidate follow-ups, not fixed quietly)

1. `GettingStartedSetting` disables the toggle when the preferences read errored
   (`disabled = isPending || isError || isWriting`), so the escape hatch is
   unreachable for the session; no explicit retry beyond refetch-on-focus.
2. The import's own failed `writePreference` retries only next launch, while a
   *competing* write's failure now retries in-session.
3. The effect re-creates `importing`/`retryPending` locals when `enabled`
   toggles, so a failure in the disabled gap can be missed.
