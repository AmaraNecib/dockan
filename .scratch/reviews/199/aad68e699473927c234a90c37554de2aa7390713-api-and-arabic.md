## Typecheck of the fixed snippets against installed packages

Scratch file compiled with the repo's `tsc@5.9.3`, `strict`, `moduleResolution:
Bundler`, importing `@tanstack/react-router@1.170.31` and
`@tanstack/react-query@5.101.4`.

Negative controls (errors expected, proving the findings are real):
```
check.tsx(12,3): error TS2322: Type '(error: any, errorInfo: any) => void' is not
  assignable to type '(error: Error) => void'.
  Target signature provides too few arguments. Expected 2 or more, but got 1.
```
```
Property 'getNextPageParam' is missing ... but required in type
'{ pages: number; getNextPageParam: GetNextPageParamFunction<...> }'.
```

Final fixed snippets: `tsc` exit 0 (all of the following compile):
- `onError: (error) => …`, `onCatch: (error, errorInfo?: ErrorInfo) => …`
  (optional second param is assignable where a 2-required-param one is not).
- `prefetchInfiniteQuery({ …, getNextPageParam, pages: 3 })`.
- `useParams({ from: dashboardRoute.id })`.
- `validateSearch` `numberOrDefault` helper.
- form `handleSubmit(event: FormEvent<HTMLFormElement>)` with `preventDefault`.
- `useQuery` `isPending` gate with a defined-data branch before reading `data`.
- `AuthProvider` that imports the router instead of calling `useRouter()`.

Source reads backing the behavioural claims:
- `query-core/src/queryObserver.ts`: `const isLoading = isPending && isFetching`
  — a first fetch paused offline is `isPending` true, `isFetching` false.
- `query-core/src/queryClient.ts`: `ensureQueryData` returns cached data and only
  background-refetches when `revalidateIfStale` (prose in
  `load-ensure-query-data.md` matches).
- `router-core/src/route.ts:1301`: `onCatch?: (error: Error) => void` (route
  option) vs `react-router/src/router.ts` `defaultOnCatch: (error, errorInfo)`.
- `react-router/src/Match.tsx`: `routeOnCatch?.(error, errorInfo)` and
  `React.createElement(routeNotFoundComponent!, error as any)` — `notFound({
  data })` reaches the component as props; a route match has no `data`.
- `router-core/src/load-client.ts`: `preloadStaleTime` selects a `staleAge` and
  triggers a reload; `preloadGcTime` is the garbage-collection setting.
- `router-core/src/utils.ts` `StrictOrFrom` → `RouteIds`; `router-core/src/link.ts`
  `FromPathOption` → `RoutePaths`; `router-generator` `inferFullPath` strips
  pathless segments — so hooks need `Route.id` while `Link`/`navigate` take a URL
  path (`Route.fullPath`).
