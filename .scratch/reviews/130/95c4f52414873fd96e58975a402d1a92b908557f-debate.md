## Accepted risks

- The warning renders only inside the inline create panel, so a typed-only variant
  submit is still unnudged; folding the hard `needsChoice` gate would create the
  block the issue forbids.
- Which of two equally folded variants is named is list order (documented,
  pinned); it is a tie-break, not the wrong-debtor class.
- The function's safety leans on the UI's `needsChoice` gate; the doc comment
  states that coupling.
