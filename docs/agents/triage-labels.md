# Triage labels

Use these GitHub labels for the five canonical triage roles.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Work is waiting on information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an agent. |
| `ready-for-human` | `ready-for-human` | The issue needs a human to implement it. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

When a skill names a triage role, apply its matching GitHub label.
