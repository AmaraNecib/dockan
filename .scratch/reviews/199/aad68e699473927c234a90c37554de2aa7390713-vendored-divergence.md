## `npx skills update` exposure

- If the updater rewrites the vendored set, it can clobber up to 334 added lines
  across 16 files per tree — i.e. every fix from both review rounds. Two rounds
  of review-fix churn (389 + 170 lines) would have to be re-applied.
- The exposure is concentrated: `tanstack-router-best-practices` holds 13 of the
  16 touched files and 383 of the 531 churned lines (72%); `tanstack-query` is a
  single 872-line file with 47 changed lines.

## What the repo actually uses

- Real dependencies: `@tanstack/react-router@1.170.31`,
  `@tanstack/react-query@5.101.4` (and `router-core@1.171.26`,
  `query-core@5.101.4`).
- Examples that import packages this repo does **not** depend on: `qs`,
  `jsurl2`, `query-string`, `@tanstack/zod-adapter`,
  `@tanstack/router-valibot-adapter`, `@tanstack/config`.
- `tanstack-config` (343 lines, 5.1% of the vendored lines) is about
  `@tanstack/config`, which no `package.json` in this repo references. Its two
  examples were also wrong before this round (`tanstackEslintConfig`,
  `tanstackPublishConfig` are not exports).

## Decision inputs for the owner (no recommendation)

- Keep-everything: 80 files / 13,566 lines under two mirrors; ~8% already
  locally patched; a single upstream sync can overwrite 668 added lines.
- Drop `tanstack-config` only: removes 1 file / 343 lines per tree (686 across
  both), 0 repo dependencies affected, and removes the only tree where every
  example targets an unused package.
- Drop the mirrors in favour of one tree + a generated copy: halves the file
  count (80 → 40) and removes the divergence class the delta review caught.
- Pin the upstream source SHA and vendor deliberately: makes the 334-line
  divergence explicit and reviewable, at the cost of owning the sync.
