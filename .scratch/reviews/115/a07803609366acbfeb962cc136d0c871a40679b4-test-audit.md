## Edge-case hunter

Findings (verbatim summary) and disposition:

1. **🟠 Two-key clear can half-apply with no per-flag signal.** `setVisible(true)`
   fires two independent writes; if one lands and the other fails the alert is
   generic and the other flag is not auto-retried. **Fixed**: added
   `surfaces a half-applied clear instead of reading it as success` (fails only
   the 2nd write, asserts `completed="false"`, `dismissed="true"` unchanged,
   `role="alert"`, toggle stays off). The generic message is accepted — the
   control is a single boolean, and retrying the click converges because both
   writes are idempotent.
2. **🟠 Genuinely-complete shop silently re-records the milestone.** **Accepted,
   by design** (`115-design.md` §1): clearing `completed` on a complete shop is
   re-recorded by the next `onboardingProgress` read because there is nothing
   left to teach. Recorded as a deliberate behaviour, not a bug.
3. **🟡 Paired-write race (toggle off while on-writes in flight).** **Deferred**;
   the final state is whichever two independent queues settle last, and the
   failure path already surfaces. Not worth a second two-flag coordination
   layer for a loopback write (see wisdom 2026-10-15-*shared-reset*: don't add
   optimistic machinery for a same-machine write).
4. **🟡 A throwing write-settled listener skips the rest.** **Fixed**:
   `notifyPreferenceWriteSettled` now isolates each observer (runs in a promise
   `finally`, where a throw would be an unhandled rejection).
5. **🟡 Read-error has no explicit retry control.** **Accepted**: the shared
   preferences query is refetched on mount/focus, and the section says so.
6. **🟡 Loading flicker (toggle reads "on" while disabled).** **Accepted**,
   cosmetic; settings does not render until `settingsGet` settles.
7. **🟡 Non-`"false"` values untested at the server boundary.** **Fixed**: the
   router test now refuses `"yes"`, `"0"`, `"False"`, `""`.
8. **🟠 5 s deadlock sentinel could false-fail on a loaded runner.** **Fixed**:
   budget raised to 15 s and the timer is cleared in `finally`.
9. **🟠 E2E order dependency for the "panel returns" assertion.** **Accepted**:
   the spec file documents the shared-DB ordering contract, `beforeAll` resets
   records per `--repeat-each` group, and the "completing every step" test runs
   after. A future reorder is guarded by the existing comment.
