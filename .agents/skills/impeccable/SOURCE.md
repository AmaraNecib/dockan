# Source

**Origin:** Third-party toolchain — impeccable (v3.9.1).
**From:** distributed via its own update channel; run `npx impeccable update` from a project (or the skill's context.mjs) to update
**Get it:** npx impeccable / the impeccable npm package; skill ships as this folder
**License:** not declared
**Notes:** THE umbrella design skill. All 16 standalone design skills (adapt, animate, audit, bolder, clarify, colorize, critique, delight, distill, layout, optimize, overdrive, polish, quieter, shape, typeset) are sub-commands inside it — see reference/*.md. Requires `node impeccable/scripts/context.mjs` setup per session.
